# Конфигурация

Система настраивается двумя способами:

1. **ENV-переменные + `/config/config.json`** — для развёртывания (Docker),
   читаются на старте. ENV имеет приоритет над файлом.
2. **Настройки в БД** (web-админка `/settings`) — каталоги сканирования,
   итог последнего скана и пр. ключи-значения.

> Контракт развёртывания (ENV) сохраняется ради обратной совместимости с уже
> опубликованными установками. Не переименовывайте переменные без MAJOR-версии.

## ENV-переменные (развёртывание)

### База данных

| Переменная | Значения | Описание |
|---|---|---|
| `EOPDS_DB_TYPE` | `postgres`, `sqlite` | Тип БД |
| `EOPDS_DB_HOST` | хост | PostgreSQL host |
| `EOPDS_DB_PORT` | порт | PostgreSQL port (по умолчанию 5432) |
| `EOPDS_DB_NAME` | имя | имя БД |
| `EOPDS_DB_USER` | пользователь | пользователь БД |
| `EOPDS_DB_PASSWORD` | пароль | пароль БД |
| `EOPDS_DB_PATH` | путь | путь к файлу SQLite (для `sqlite`) |

### Прочее

| Переменная | Описание |
|---|---|
| `TZ` | часовой пояс контейнера |
| `EOPDS_ROOT_LIB` | путь к библиотеке (по умолчанию `/books`) |
| `EOPDS_UPDATE_SOURCE` | источник проверки версий (`https://eopds.ru/latest.json` / `github` / `off`) |
| `EOPDS_FORUM_SOURCE` | источник последних тем форума (`https://eopds.ru/api/latest-topics`) |

## config.json (единый файл конфигурации)

Основной источник настройки — `/config/config.json` (создаётся мастером
установки `/install`, редактируется с хоста). Он объединяет БД, каталоги
сканирования, корневого администратора и адрес сервера. ENV `EOPDS_*`
переопределяют соответствующие поля.

## Настройки в БД (`/settings`)

Часть параметров хранится в таблице настроек (ключ-значение) и правится через
web-админку (`/settings`):

- `scan.paths` — каталоги сканирования (JSON-массив путей).
- `scan.last` — итог последнего сканирования (JSON `ScanSummary`).

См. также [go/install.md](../go/install.md) и [go/scanner.md](../go/scanner.md).
