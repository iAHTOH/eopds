# Конфигурация

Система настраивается двумя способами:

1. **ENV-переменные** — для развёртывания (Docker), читаются на старте.
2. **constance** (web-админка `/admin/` → Settings) — настройки приложения, хранятся в БД.

> Контракт развёртывания (ENV) сохраняется ради обратной совместимости с уже
> опубликованными установками. Не переименовывайте переменные без MAJOR-версии.

## ENV-переменные (развёртывание)

### База данных

| Переменная | Значения | Описание |
|---|---|---|
| `EOPDS_DB_TYPE` | `postgres`, `sqlite` | Тип БД |
| `EOPDS_DB_HOST` | хост | PostgreSQL host |
| `EOPDS_DB_PORT` | порт | PostgreSQL port (по умолчанию 5432) |
| `EOPDS_DB_NAME` | имя | имя БД |
| `EOPDS_DB_USER` | пользователь | пользователь БД |
| `EOPDS_DB_PASSWORD` | пароль | пароль БД |
| `EOPDS_DB_PATH` | путь | путь к файлу SQLite (для `sqlite`) |

### Прочее

| Переменная | Описание |
|---|---|
| `TZ` | часовой пояс контейнера |
| `EOPDS_ROOT_LIB` | путь к библиотеке (по умолчанию `/books`) |
| `EOPDS_UPDATE_SOURCE` | источник проверки версий (`https://eopds.ru/latest.json` / `github` / `off`) |
| `EOPDS_FORUM_SOURCE` | источник последних тем форума (`https://eopds.ru/api/latest-topics`) |

## constance (приложение)

Полный список параметров — в web-админке (`/admin/` → Constance → Settings).
Ключевые группы:

- **General** — язык, путь к библиотеке, расширения книг.
- **Server** — авторизация, пагинация, обложки.
- **Scanner** — движок (`python`/`go`), воркеры, пути к бинарнику.
- **Scanner Shedule** — cron-расписание.
- **Telegram Bot** — токен, авторизация.
- **Converters** — пути к конвертерам.
- **Log & PID** — пути к лог- и pid-файлам.

Подробное описание каждого параметра — по мере стабилизации; см. также
исходный `eopds/settings.py` → `CONSTANCE_CONFIG`.
