# Версионирование и обновления

## Схема версий (SemVer)

Проект следует SemVer: `MAJOR.MINOR.PATCH`.

- **MAJOR** — несовместимые изменения (ломающие контракт развёртывания, схемы БД, API).
- **MINOR** — новая функциональность с обратной совместимостью.
- **PATCH** — исправления ошибок.

### Единый источник версии

Версия хранится в одном месте — файле `VERSION` в корне репозитория (строка вида `0.47.0`).

Она передаётся:
- **В Go** — при сборке: `-ldflags "-X main.version=$(cat VERSION)"`.
- **В Python** — через `eopds_web_backend/settings.py` (`VERSION`) при старте (читается из `VERSION`).

Никаких дублирующих версий в коде — только `VERSION`.

## Версия схемы БД

Схема БД имеет собственный `schema_version` (целое). Он хранится в таблице
служебных метаданных (`eopds_meta` со строкой `schema_version`).

Правила:
- Изменение структуры таблиц/индексов → инкремент `schema_version` + миграция.
- Go-сервис при старте сравнивает `schema_version` БД с ожидаемым и:
  - при равенстве — работает;
  - при расхождении — **не падает молча**, а логирует и отдаёт `/api/health` со статусом `degraded`.

## Проверка обновлений

Go-сервис предоставляет endpoint `GET /api/upgrade-check`, который сравнивает
текущую версию с последней доступной.

Источник последней версии конфигурируемый (ENV `EOPDS_UPDATE_SOURCE`):
- `https://eopds.ru/latest.json` — **приоритетный** (контролируемый нами источник);
- GitHub Releases API — запасной вариант;
- `off` — проверка отключена.

Формат `latest.json` (см. [forum.md](forum.md) и [go/api.md](go/api.md)):

```json
{
  "version": "0.48.0",
  "url": "https://eopds.ru/topic/5/release-notes",
  "released_at": "2026-01-15",
  "notes": "Кратко о главном в релизе",
  "min_schema_version": 3
}
```

Ответ `/api/upgrade-check`:

```json
{
  "current": "0.47.0",
  "latest": "0.48.0",
  "update_available": true,
  "url": "https://eopds.ru/topic/5/release-notes",
  "checked_at": "2026-01-16T10:00:00Z"
}
```

Проверка выполняется с таймаутом (3с) и кэшируется (по умолчанию 1 час),
чтобы не зависеть от доступности внешнего источника.
