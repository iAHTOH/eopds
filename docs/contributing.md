# Как внести вклад в проект

Спасибо за интерес к Easy OPDS! Мы рады любому вкладу: коду, документации,
переводам, сообщениям об ошибках и идеям.

## Способы помощи

- **Баг-репорт / вопрос** — создайте тему на форуме [eopds.ru](https://eopds.ru)
  или issue на GitHub.
- **Перевод** — см. [translating.md](translating.md).
- **Документация** — правьте `docs/` и присылайте PR.
- **Код** — см. правила ниже.

## Правила для кода

- Go — чистый stdlib; внешние зависимости только SQL-драйверы (`modernc.org/sqlite`, `jackc/pgx`).
- CSS/JS — без фронтенд-фреймворков.
- Не ломать контракт развёртывания (`EOPDS_DB_*`, порт 8080, `/config`, `/books`).
- Версионирование — SemVer, единый `VERSION`.
- Документация обновляется в том же PR (см. правило «Documentation First»).

## Процесс

1. Форкните репозиторий.
2. Создайте ветку (`feature/...` или `fix/...`).
3. Внесите изменения, добавьте/обновите документацию и тесты.
4. Откройте пулл-реквест с описанием изменений.

## Структура репозитория (кратко)

```
eopds-go/              # Go: сканер + админка + веб-библиотека (подкоманды scan / serve)
docs/                  # документация (этот каталог)
```

См. также [architecture.md](architecture.md).
