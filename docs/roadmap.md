# План развития (Roadmap)

Дорожная карта проекта. Порядок и состав может меняться; приоритет —
обратная совместимость и постепенность.

## Уже сделано

- [x] Экспериментальный **Go-сканер** (`eopds scan`): параллельный обход,
      windows-1251, ранний выход после `</description>`, паритет с Python.
- [x] Переключение движка сканера (`EOPDS_SCANNER_ENGINE=python|go`).
- [x] Переименование Go-модуля `scanner_go` → **`eopds-go`** с заделом на подкоманды.
- [x] Базовая структура документации (`docs/`) + правила проекта.

## В работе / следующие шаги

### Этап 1 — Фундамент Go-монолита
- [ ] `cmd/eopds` с подкомандами `scan`, `admin` (+ будущий `serve`).
- [ ] Пакет `internal/version` (VERSION → `-ldflags`), git-commit, build-time.
- [ ] Пакет `internal/config`: чтение ENV, совместимость с `EOPDS_DB_*`.
- [ ] Пакет `internal/store`: интерфейс `Store` + реализации SQLite (`modernc.org/sqlite`)
      и PostgreSQL (`jackc/pgx`); MySQL не поддерживается.
- [ ] `schema_version` в БД + проверка при старте.

### Этап 2 — Go-админка (stdlib, тема портала)
- [ ] HTTP-сервер админки (`internal/admin`), html/template.
- [ ] API: `/api/health`, `/api/version`, `/api/upgrade-check`, `/api/forum/latest-topics`.
- [ ] Дашборд: статистика библиотеки, дата последнего скана, что читают пользователи.
- [ ] Современный layout + меню; темы (светлая/тёмная/серая), память выбора.
- [ ] Виджеты: «Обновления» (eopds.ru/latest.json), «Актуальные темы форума».
- [ ] Адаптивность / мобильные браузеры.

### Этап 3 — Действия и авторизация
- [ ] Кнопки: запуск сканирования, очистка БД, просмотр логов.
- [ ] Вход (сессия + CSRF), роли (суперпользователь/админ).
- [ ] Поэтапный перенос управления (жанры, настройки constance, пользователи).

### Этап 4 — Единый портал
- [ ] Перенос веб-фронта и OPDS на Go (`eopds serve`), общие CSS/JS/шаблоны с админкой.
- [ ] Единая тема, меню, локализация для всего портала.

### Этап 5 — Постепенный отказ от Python
- [ ] Аудит оставшейся функциональности Django (телеграм-бот, конвертация, читалка).
- [ ] Перенос по частям с сохранением контракта развёртывания.

## Улучшения Go-сканера (бэклог)

- [ ] Пакетная запись в БД (устранить узкое место — однопоточную запись).
