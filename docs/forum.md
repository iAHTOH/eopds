# Форум и интеграция с eopds.ru

Сайт проекта — [https://eopds.ru](https://eopds.ru). Там размещаются:
- анонсы и релизы;
- руководства по установке;
- техподдержка;
- отзывы пользователей.

Админка использует форум как источник:
1. **Актуальные темы** — виджет на дашборде.
2. **Проверка обновлений** — `latest.json` (см. [versioning.md](versioning.md)).

## Сайт можно дорабатывать под наши нужды

Так как сайт принадлежит автору проекта, на нём можно ввести удобные машинночитаемые
endpoint'ы. Это снимает зависимость от «хрупкого» HTML-парсинга и GitHub rate-limit.

### Требуемый endpoint: последние темы

`GET https://eopds.ru/api/latest-topics`

Ответ (JSON):

```json
{
  "from": "2026-01-16T09:00:00Z",
  "topics": [
    {
      "title": "Установка через docker-compose с внешней PostgreSQL",
      "url": "https://eopds.ru/topic/4/установка-easy-opds-через-docker-compose-с-внешней-postgresql/1",
      "category": "Техподдержка",
      "replies": 0,
      "created_at": "2026-01-10T12:00:00Z",
      "last_post_at": "2026-01-12T08:30:00Z"
    }
  ]
}
```

Можно реализовать как статический файл `latest-topics.json`, обновляемый
планировщиком форума, либо динамический endpoint. Админка не требует больше
полей, чем перечислено.

### Требуемый endpoint: последняя версия

`GET https://eopds.ru/latest.json` — формат см. в [versioning.md](versioning.md).

## Поведение админки при недоступности форума

- Таймаут запроса — 3 секунды.
- Результат кэшируется (по умолчанию 30 минут).
- При ошибке/таймауте блок «Форум» на дашборде **скрывается** (без ошибки для пользователя).
- Адрес источника конфигурируется (`EOPDS_FORUM_SOURCE`).
