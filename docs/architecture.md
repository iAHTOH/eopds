# Архитектура Easy OPDS

## Обзор

Easy OPDS — система для домашней библиотеки с OPDS-каталогом, веб-интерфейсом и
административной панелью. Исторически система написана на Python/Django; идёт
постепенный перенос на **Go** с сохранением обратной совместимости.

## Компоненты

```
┌─────────────────────────────────────────────────────────────┐
│                      Единая PostgreSQL/SQLite                │
└─────────────────────────────────────────────────────────────┘
        ▲                 ▲                        ▲
        │                 │                        │
┌───────────────┐  ┌──────────────┐        ┌──────────────────┐
│ Python/Django │  │  Go: scan    │        │   Go: admin      │
│  (web, OPDS)  │  │ (сканер)     │        │ (дашборд, API)   │
└───────────────┘  └──────────────┘        └──────────────────┘
```

### Python/Django (оперативно)

Отвечает за:
- веб-интерфейс каталога (`/web/`);
- OPDS (`/opds/`);
- онлайн-читалку;
- конвертацию книг (`fb2cng`);
- часть сканирования (по умолчанию `EOPDS_SCANNER_ENGINE=python`).

### Go (`eopds-go`)

Единый модуль `eopds-go` с подкомандами:
- `scan` — параллельный сканер коллекции (заменяет Python-сканер при `EOPDS_SCANNER_ENGINE=go`);
- `admin` — современная админка + HTTP API (версия, здоровье, обновления, форум);
- `serve` — (в перспективе) перенос веб-фронта и OPDS на Go.

Подробнее: [go/README.md](go/README.md).

## Стек

| Компонент | Технология |
|---|---|
| Веб/OPDS/сканер (оперативно) | Python 3.13 + Django 5.1 |
| Сканер/админка (новое) | Go 1.23, stdlib (`net/http`, `html/template`, `database/sql`) |
| БД приложения | PostgreSQL (рекомендуется) или SQLite (файловая) |
| Конвертация книг | fb2cng (статический Go-бинарник) |

**MySQL/MariaDB не поддерживаются** (осознанное решение).

## Принципы

1. **Один контракт развёртывания.** Должны работать ENV `EOPDS_DB_TYPE`,
   `EOPDS_DB_HOST`, `EOPDS_DB_PORT`, `EOPDS_DB_NAME`, `EOPDS_DB_USER`,
   `EOPDS_DB_PASSWORD`, порт `8080`, каталоги `/config` и `/books`.
2. **Минимум зависимостей.** Go — чистый stdlib; внешние только SQL-драйверы
   (`modernc.org/sqlite`, `jackc/pgx`).
3. **Маленький и быстрый.** Без фронтенд-фреймворков; ванильный CSS/JS;
   поддержка мобильных браузеров; без CGO.
4. **Поэтапный перенос.** Django не переписывается разом — выносим в Go по частям.
