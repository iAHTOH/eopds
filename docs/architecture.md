# Архитектура Easy OPDS

## Обзор

Easy OPDS — система для домашней библиотеки с OPDS-каталогом, веб-интерфейсом и
административной панелью. Система написана на **Go** (единый модуль `eopds-go`,
чистый stdlib без CGO). Историческая Python/Django-реализация удалена из проекта;
её код остаётся доступным только в истории git (до коммита перехода на Go).
