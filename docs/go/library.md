# Веб-библиотека (Go) — раздел `/library`

Публичный веб-интерфейс библиотеки в стиле классического EOPDS
(Foundation, тёмная тема, акцент `#f15a23`). Сервер отдаёт HTML-страницы;
это не JSON API (см. [api.md](api.md)).

## Маршруты

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/` | Главная (приветствие, картинка, интро про OPDS) |
| GET | `/library` | **Каталоги**: папки первого уровня в корне сканирования |
| GET | `/library/catalog/{id}` | Содержимое каталога: подпапки/архивы и книги |
| GET | `/library/books` | Книги: алфавитный указатель или список |
| GET | `/library/authors` | Авторы: алфавитный указатель или список |
| GET | `/library/series` | Серии: алфавитный указатель или список |
| GET | `/library/genres` | Жанры: плоский список (постранично) |
| GET | `/library/book/{id}` | Карточка книги |
| GET | `/library/book/{id}/cover` | Обложка книги (ленивое извлечение, кэш) |
| GET | `/library/book/{id}/download` | Скачивание файла книги (только авторизованным) |
| GET | `/library/search` | Поиск (`?q=` и `?by=title\|author\|series`) |
| GET | `/library/suggest` | JSON-подсказки живого поиска (`?q=&by=`) |
| GET | `/settings` | Настройки, в т.ч. очистка библиотеки (admin) |

Под шапкой — **строка поиска** и **меню категорий** (Каталоги / Книги /
Авторы / Жанры / Серии) с выпадающими подменю языковых фильтров при
наведении. В шапке — переключатель темы День/ночь.

## Каталоги

«Каталог» — папка **первого уровня** в корне сканирования (`/books`).
Внутри каталога могут быть файлы книг, zip-архивы (отдельные узлы с иконкой
zip) и **вложенные папки** (например, `Журнал радио/1932`). Вложенные папки
показываются как папки и не считаются отдельными каталогами; книги видны на
уровне своего непосредственного контейнера (папки или архива), без рекурсии.

Иерархия хранится в `catalogs(parent_id, name, path, kind)`
(`kind`: `0` папка, `1` zip). `books.catalog_id` указывает на
**непосредственный контейнер** книги. При сканировании иерархия строится/обновляется,
а каталоги, пропавшие с диска (без книг и без детей), удаляются (`PruneCatalogs`).

## Живой поиск (autocomplete)

Строка поиска под шапкой шлёт запросы на `GET /library/suggest?q=<строка>&by=<тип>`
(тип: `title` / `author` / `series`) с задержкой ~220 мс, начиная с 2 символов.
Ответ — JSON `{"items":[{"id","title","authors":[],"annotation","format"}]}`.
Каждый элемент — мини-карточка (обложка `/library/book/{id}/cover`, название,
авторы, обрезка аннотации); клик ведёт на полную карточку книги.
Тип поиска выбирается в выпадающем подменю кнопки «Найти» (как у пунктов меню).

## Скачивание книг

`GET /library/book/{id}/download?fmt=<fmt>` отдаёт файл книги как вложение
(`Content-Disposition: attachment`), имя — по названию книги (транслит-безопасный
`filename*=UTF-8''`). **Доступно только авторизованным** (гость → `303` на `/login`).
Источник — обычный файл на диске или элемент ZIP-архива (определяется по `path`).

Параметр `fmt`:

| fmt | Результат |
|---|---|
| пусто или `<исходный формат>` | файл как есть (`application/x-fictionbook+xml`, `application/epub+zip`, …) |
| `fb2+zip` | упаковка файла в ZIP «на лету» |
| прочие (`epub3`, `kepub`, `mobi`, `azw8`, `kfx`, `pdf`, `txt`, `md`) | пока `404` — конвертер не подключён (см. roadmap) |

Побочное (штатное) действие: скачивание авторизованным пользователем кладёт книгу
на его **книжную полку** (`bookshelf`, обновляется `last_read_at`) — для будущей
страницы «Моя полка».

На карточке книги показывается блок «Скачать:» со ссылками доступных форматов
(исходный + `fb2+zip` для fb2). Конвертация в другие форматы и OPDS-отдача —
в планах ([roadmap.md](../roadmap.md)).

## Роли и доступ

| Роль | Просмотр библиотеки | Скачивание | Скан/Настройки |
|---|---|---|---|
| Гость (не авторизован) | нет (→ `/login`) | нет | нет |
| Читатель (`reader`) | да | да | нет (403) |
| Модератор (`moderator`) | да | да | нет (403) |
| Администратор (`admin`/root) | да | да | да |

В главном меню пункты «Сканирование» и «Настройки» показываются только
администратору; форма запуска скана скрыта для остальных.

## Обложки

Обложка извлекается из FB2 (`<coverpage><image>` + соответствующий `<binary>`)
**лениво** — при первом запросе `/library/book/{id}/cover`, затем кэшируется
в `/config/covers/`. В списках карточка с `onerror` подставляет заглушку
`/static/img/eopds_nocover.webp`. Для не-FB2 или книг без обложки — 404.

## Параметры запросов

Общие для `books`/`authors`/`series`:

- `lang` — фильтр по набору первого символа названия:
  `0` — все, `1` — кириллица, `2` — латиница, `3` — цифры, `9` — прочее.
  Применяется только к книгам; для авторов/серий собирается, но не фильтрует.
- `chars=<префикс>` — **под-уровень** указателя: показать префиксы длиной
  `len(prefix)+1`, начинающиеся с `chars`.
- `prefix=<префикс>` — **список** записей, начинающихся с `prefix` (постранично).
- `page=<n>` — номер страницы (с 1), размер страницы — 60.

Дополнительно для `/library/books`:

- `author=<id>`, `series=<id>`, `genre=<id>` — фильтр книг по связи.

Для `/library/search`: `q=<строка>` — подстрочный поиск; `by=title|author|series`
выбирает тип (title — поиск по названию; author/series ведут в раздел с
префиксом). Числовой фильтр `lang` (0..9) запоминается в cookie `lang_num`
и не влияет на локаль интерфейса (ru/en).

## Алгоритм алфавитного указателя

1. Запрос без `prefix`: строим префиксы длиной 1 (для книг — с учётом `lang`).
2. Для каждого префикса считаем количество записей:
   - если `count < 300` (порог `EOPDS_SPLITITEMS`) — ссылка сразу на список
     (`?prefix=`), иначе — на под-уровень (`?chars=`) с префиксом длиной +1.
3. Максимальная глубина детализации — 3 символа.

Поведение совпадает с классическим интерфейсом (`/web/book/?lang=N`).

## Каркас страниц

- Единый верхний блок (`site_top`): логотип + название, меню разделов
  (видно **только авторизованным**), выбор языка, вход/выход.
- Футер (`site_footer`) отображается **только авторизованным** и содержит сетку:
  - верхняя строка — **случайная книга** (полная карточка + аннотация);
  - нижняя: слева — **новые поступления** (3 последние книги), справа —
    **статистика** (книги/авторы/жанры/серии) и `Easy OPDS · v<версия>`.

Шаблоны — `eopds-go/internal/admin/templates/`:
`chrome.html`, `lib_parts.html`, `layout.html`, `library*.html`, `library_catalog.html`.
Картинки интерфейса — `internal/admin/static/img/` (logo, homelib, nocover).

## Схема БД

`books.lang_code` (SMALLINT) вычисляется при сканировании по первому значимому
символу `search_title` (`1` кириллица, `2` латиница, `3` цифры, `9` прочее).
Существующие записи заполняются миграцией `0002_book_lang_code.sql`
(`schema_version = 2`). См. [../db-schema.md](../db-schema.md).
