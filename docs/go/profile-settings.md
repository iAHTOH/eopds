# Профиль и раздел «Настройки»

Страницы `/settings/profile` (профиль пользователя) и `/settings` (раздел
настроек с левым меню и ролевой фильтрацией).

## Профиль (`/settings/profile`)

Доступен любому **зарегистрированному** пользователю. Без левого меню —
это самостоятельная страница личных настроек.

### Что редактируется

| Поле | Поле формы | Ограничения |
|---|---|---|
| Имя | `display_name` | ≤ 100 символов, обрезается; показывается в приветствии вместо логина |
| Email | `email` | грубая валидация; нужен для уведомлений (после настройки SMTP) |
| Язык интерфейса | `pref_lang` | `''` (по умолчанию) / `ru` / `en` |
| Тема | `pref_theme` | `''` / `light` / `dark` |
| Шрифт читалки | `read_font` | `''` / `serif` / `sans` / `mono` |
| Размер шрифта | `read_font_size` | 50–300 %, 0 — по умолчанию |
| Аватар | файл `avatar` | JPEG/PNG/GIF, ≤ 4 МБ до обработки, обрезка в квадрат 512×512, сохраняется как JPEG |

**Логин (`username`) не меняется.** Роль и признак 18+ правятся модератором/админом,
в профиле только отображаются.

### Предпочтения и cookie

Выбранные язык и тема сразу пишутся в cookie (`lang`, `theme`) — применяются
без перезагрузки. Пока cookie не задан, `/`-страницы используют
`pref_theme` / `pref_lang` пользователя (см. `resolveThemeFor` / `resolveLangFor`),
затем — значения запроса/браузера/дефолт.

### Смена пароля

Форма POST `/settings/profile/password`: `old_password`, `new_password`,
`confirm_password`. Новый пароль — минимум 8 символов, должен совпадать с
подтверждением, текущий проверяется по хешу. Успех → flash + событие
`profile.password` (уровень warn).

### Аватар

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/settings/profile/avatar` | загрузка (`avatar`) или удаление (`delete=1`) |
| GET | `/settings/avatar` | отдать аватар текущего пользователя |
| GET | `/settings/avatar?u=<id>` | аватар другого пользователя (для шапки/комментариев) |

Файл хранится в `<config>/avatars/u<id>.jpg`. Отсутствие файла → `404`.

### Выход со всех устройств

POST `/settings/profile/logout-others` удаляет все сессии пользователя, кроме
текущей (по cookie `eopds_session`). Возвращает число закрытых сессий через
событие `profile.logout_others` (уровень warn).

## Раздел «Настройки» (`/settings`)

Доступ: роль **не ниже moderator** (иначе `403`). Левое меню строится по роли
(`settingsNav`), контент — по `?sec=`.

### Пункты меню по ролям

**Администратор** (сгруппировано):

| Группа | Пункты (`?sec=`) |
|---|---|
| Пользователи | `users`, `requests`, `invites` |
| Библиотека | `scan` — каталоги сканирования, каталоги библиотеки, опасная зона |
| Система | `general` (SMTP и прочее), `log` |
| Обслуживание | `updates` — проверка обновлений портала (в конце) |

**Модератор:** `users`, `requests`.

Без `?sec=` открывается первый доступный пункт (у админа/модератора — `users`).
Неизвестный или недоступный `sec` → показывается первый доступный.

Разделы `invites`, `requests`, `log`, `updates` пока показывают заглушку
«Раздел скоро появится». `scan` содержит каталоги сканирования и «опасную зону»
(очистку библиотеки) — они перенесены сюда, т.к. связаны со сканированием.

### Связанные действия

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/settings/scan-dirs` | сохранить каталоги сканирования (→ `/settings?sec=scan#scan`) |
| POST | `/settings/clear-library` | очистка библиотеки (требует `confirm=yes`; → `/settings?sec=scan#danger`) |

## Шапка сайта (меню аккаунта)

Для зарегистрированных вместо иконки выхода — **аватар** (фото или буква-заглушка).
При наведении — выпадающее меню (как у «Найти»):

1. **Профиль** — всем;
2. **Дашборд** — всем;
3. **Настройки** — moderator/admin;
4. **Выход** — всем (POST `/logout`).

У гостя — ссылка «Войти» (`/login`) с иконкой двери.

## Схема БД

Миграция `0005_user_profile.sql` (PG/SQLite) добавляет в `users`:
`display_name`, `avatar`, `allow_adult` (по умолчанию включён), `pref_lang`,
`pref_theme`, `read_font`, `read_font_size`. См. [../db-schema.md](../db-schema.md).

## Store API

`UpdateProfile(ProfileUpdate)` — имя/email/предпочтения (Email `nil` — не менять),
`SetUserAvatar(id, name)` (`` — удалить), `DeleteUserSessionsExcept(userID, keepID)`.
