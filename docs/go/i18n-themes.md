# Локализация и темы (Go-ядро)

В Go-ядре `eopds` реализованы две сквозные подсистемы оформления:
**темы** и **языки (i18n)**. Они применяются ко всему сайту через единый
каркас (`templates/layout.html`), поэтому новые страницы получают их «из коробки».

## Темы

- Отдельные CSS-файлы без цветов в базовой структуре:
  - `static/css/base.css` — только структура и переменные темы `var(--*)`;
  - `static/css/theme-dark.css` — тёмная (в духе старой главной: фон `#0d0503`,
    акцент `#f15a23`, текст `#bda789`);
  - `static/css/theme-light.css` — светлая.
- Выбор темы: кнопка-иконка в верхнем меню (солнце/луна), параметр
  `?theme=dark|light`, сохраняется в cookie `theme` (1 год). По умолчанию — `dark`.
- Favicon — `static/img/favicon.ico` (взят из старого проекта).
- Список известных тем — `isKnownTheme()` (`internal/admin/helpers.go`).
  Чтобы добавить тему: создайте `theme-<name>.css` и добавьте имя в `isKnownTheme`.

## Языки (i18n)

Единый источник переводов — `internal/i18n/translations.json`
(плоская структура `{"lang": {"msgid": "текст"}}`). Встраивается через
`go:embed` — **без `.po`/`.mo`**. Список языков — `internal/i18n/LINGUAS`.

- Пакет `internal/i18n`:
  - `Load()` — читает встроенные переводы;
  - `Languages()` — доступные языки;
  - `Translator(lang)` — функция перевода с откатом на `en`.
- В шаблонах строки выводятся через `{{T "ключ"}}`, названия языков — `{{langName .}}`.
- Язык определяется (`resolveLang`): `?lang=`, cookie `lang`, заголовок
  `Accept-Language`, иначе `en`. Выбор сохраняется в cookie `lang`.
- Переключатель языка — выпадающий список в верхнем меню (иконка глобуса, код
  языка двумя буквами: `EN`/`RU`), **до** переключателя тем.

### Добавление строк

1. Добавьте ключ и переводы в `internal/i18n/translations.json` для всех языков.
2. Используйте `{{T "ключ"}}` в шаблоне или `tr("ключ")` в Go-коде.

### Ошибки формы

Ключи ошибок установщика — `install.err.*`. Go-код возвращает ключ,
шаблон/обработчик переводит его через `Translator`.

## Верхнее меню и админка

Каркас (`templates/layout.html`) задаёт общий вид всего сайта в духе nginx-ui:

- слева — логотип и надпись «Easy OPDS»;
- по центру — горизонтальное меню разделов: **Дашборд**, Библиотека,
  Сканирование, Настройки (активный пункт подсвечивается, `{{if eq .Nav ...}}`);
- справа — выбор языка (глобус + `EN/RU`) и кнопка переключения темы (солнце/луна).
- Меню `sticky`, адаптивно (на узких экранах скрывается).

Главная (`templates/home.html`) — дашборд с карточками статистики
(Книги/Авторы/Серии/Пользователи) и блоком «Недавно добавлено».

Каждая страница задаёт `{{define "content"}}`; в данных — поле `Nav` для
подсветки активного раздела. Новые разделы добавляются пунктом меню и
отдельным шаблоном-страницей.

## Как это связано с общим планом

Согласно [../translating.md](../translating.md) и [../roadmap.md](../roadmap.md),
цель — единый `translations.json` для всего проекта (Go + временно Django).
Текущая Go-реализация — первый шаг: файл уже встраивается в бинарник,
`.po`/`.mo` для Go больше не используются.
