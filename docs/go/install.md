# Мастер установки (Go-ядро)

Первичная настройка `eopds` выполняется через веб-мастер. Он показывается
автоматически при запуске сервера, если БД ещё не сконфигурирована/пустая.

## Как запустить

```bash
# PostgreSQL (обычный вариант для развёртывания)
EOPDS_DB_TYPE=postgres EOPDS_DB_HOST=localhost EOPDS_DB_NAME=eopds \
EOPDS_DB_USER=eopds EOPDS_DB_PASSWORD=secret \
eopds serve

# SQLite (простой режим, файл)
EOPDS_DB_TYPE=sqlite EOPDS_DB_PATH=/config/eopds.db eopds serve
```

После запуска откройте `http://<host>:8080/` — при необходимости откроется
мастер установки (`/install`).

## Как это работает

1. Сервер читает конфигурацию БД: ENV `EOPDS_DB_*` (приоритет) → файл
   `/config/db.json` (создаётся мастером) → значения по умолчанию.
2. Если БД не настроена/недоступна — сервер всё равно поднимается и показывает
   мастер установки (а не падает).
3. После отправки формы мастер:
   - подключается к БД и **автоматически применяет миграции** (schema_version);
   - создаёт **единственного root-администратора** (`role=admin`, `is_root`);
   - сохраняет базовые настройки (`installed_at`, `db_type`) в таблицу `settings`;
   - сохраняет параметры БД в `/config/db.json` (если они не заданы через ENV);
   - перенаправляет на главную.

## Требования к полям

| Поле | Требование |
|---|---|
| Логин администратора | не менее 3 символов |
| Пароль | не менее 8 символов, повтор должен совпадать |
| Email | необязателен |

Пароли хранятся как `pbkdf2-sha256$<iter>$<salt>$<hash>` (PBKDF2-HMAC-SHA256,
210 000 итераций, stdlib `crypto/pbkdf2`).

## Безопасность и повторный запуск

- Повторная установка невозможна: если root-администратор существует, мастер
  сразу перенаправляет на `/` (и на уровне БД действует уникальный индекс
  «ровно один root»).
- Порядок выбора БД: PostgreSQL — основная, SQLite — простой режим.
- `/config/db.json` сохраняется с правами `0600`.

## Проверка состояния

- `GET /healthz` → `{"status":"ok","version":"..."}` (или `no-db`/`db-error`).
- Версия: `eopds version`.
