# Онлайн-читалка FB2 (`/library/book/{id}/read`)

Встроенная читалка книг формата **FB2** прямо в веб-библиотеке: сервер
преобразует тело книги (`<body>`) в безопасный HTML, браузер показывает его
постранично. Доступна авторизованным пользователям (как и скачивание).

Исходник читается из того же источника, что и для скачивания — обычный файл
на диске или элемент ZIP-архива (см. [library.md](library.md#скачивание-книг)).

## Маршруты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/library/book/{id}/read` | Страница читалки (HTML-каркас + JS) |
| GET | `/library/book/{id}/html` | Тело книги, отрендеренное в HTML-фрагмент |
| POST | `/library/book/{id}/progress` | Сохранение позиции чтения (204) |

Все три требуют авторизации (`eopds_session`; гость → `303` на `/login`).

### `GET /library/book/{id}/read`

Отдаёт страницу-читалку. Формат книги проверяется: поддерживается **только
`fb2`**; для прочих форматов — редирект `303` на карточку книги
`/library/book/{id}` (читалка не умеет рендерить epub/pdf/…).

Страница передаёт в разметку:

| Данные | Описание |
|---|---|
| `Book` | карточка книги (название, формат, id) |
| `StartPercent` | сохранённый прогресс в процентах (число, `0` если нет) |

Поведение в браузере:

- **Пагинация** по высоте окна: контент листается «страницами».
  Листать можно кнопками `‹ ›`, колесом мыши, клавишами
  `← → ↑ ↓ PageUp PageDown Space Home End`.
- **Верхняя панель закреплена** (`position: sticky`) и в тёмной теме
  принимает тёмный вид (цвета берутся из CSS-переменных темы).
- **Размер шрифта** настраивается (`A−`/`A+`, 12–28 px), запоминается в
  `localStorage` (`reader:font:<bookId>`).
- Индикатор справа показывает `NN% · <стр>/<всего>`.
- Позиция сохраняется автоматически (через ~1,2 с после перелистывания и в
  `beforeunload` через `navigator.sendBeacon`).

### `GET /library/book/{id}/html`

Возвращает отрендеренное **тело** книги как HTML-фрагмент
(`Content-Type: text/html; charset=utf-8`, без `<html>/<head>/<body>`).

Коды ответа:

| Код | Когда |
|---|---|
| `200` | успех, тело в HTML |
| `404` | книги нет / нет доступа к файлу |
| `500` | ошибка чтения файла или превышен лимит размера |
| `422` | файл прочитан, но не является FB2 (`<FictionBook>` не найден) |

Что рендерится (`eopds-go/internal/fb2render`):

- секции `section` → `<section>` + заголовки `title` → `<h2>…<h6>`;
- абзацы `p`, подзаголовки `subtitle`, `empty-line`;
- инлайн: `strong`, `emphasis` (→`<em>`), `style`, `sup`, `sub`, `strikethrough`;
- стихи `poem`/`stanza`/`v`, автор/дата стихов;
- эпиграфы `epigraph`, цитаты `cite`;
- таблицы `table`/`tr`/`td`/`th`;
- картинки `<image l:href="#id">` — встраиваются **inline** как
  `data:<mime>;base64,…` из соответствующего `<binary>` (отдельный эндпоинт
  для картинок не нужен);
- сноски: ссылки `<a type="note">` → `<a class="fb2-note-ref">`, а блок
  `<body name="notes">` выводится в конце как `<section class="fb2-notes">`
  с `<aside class="fb2-note" id="…">`.

**Весь текст экранируется** (`html.EscapeString`), поэтому фрагмент безопасно
вставлять в страницу.

> Ограничение размера: исходный FB2 читается в память целиком, предел —
> **64 МиБ** (`maxReaderSource`). При превышении — `500`. С запасом покрывает
> реальные книги коллекции (включая тексты с base64-иллюстрациями).
>
> Парсер «терпимый»: битые места не роняют рендер, а по возможности
> пропускаются (как и в сканере, `internal/fb2`). Поддерживаются кириллические
> кодировки (windows-1251 и др.) через charset-ридер.

### `POST /library/book/{id}/progress`

Сохраняет позицию чтения текущего пользователя.

Параметры (`application/x-www-form-urlencoded` или query):

| Параметр | Значение | Описание |
|---|---|---|
| `position` | строка | позиция; читалка шлёт `percent:<0..100>` (например, `percent:12.50`) |

Коды ответа:

| Код | Когда |
|---|---|
| `204` | сохранено |
| `401` | не авторизован |

Строка `position` обрезается до 64 символов. Позиция хранится в
`bookmarks.position` (одна «якорная» запись прогресса на книгу пользователя),
плюс обновляется `bookshelf.last_read_at` (книга попадает на полку, как и при
скачивании).

```bash
# пример (после логина)
curl -s -b cookiejar -X POST \
  -d 'position=percent:12.50' \
  http://localhost:8080/library/book/49934/progress
# → 204 No Content
```

## Хранение прогресса

| Где | Что |
|---|---|
| `bookmarks.position` | строка `percent:<NN.NN>` (последняя позиция) |
| `bookshelf.last_read_at` | время последнего чтения (через `AddToShelf`) |

Схема БД **не менялась** — используется существующая таблица `bookmarks`
(см. [../db-schema.md](../db-schema.md)). `schema_version` не инкрементируется.

При открытии читалки `StartPercent` вычисляется из `bookmarks.position`
(`percent:<NN>` → число; иные/битые значения → `0`).

## Ограничения

- Только **FB2**. Прочие форматы — редирект на карточку (скачивание/конвертеры
  см. [library.md](library.md), [roadmap.md](../roadmap.md)).
- Исходник ≤ 64 МиБ.
- Картинки встраиваются inline (data URI): большие иллюстрированные книги
  дают крупный HTML — это ожидаемо.
- Прогресс — процент по страницам; точная позиция (абзац/символ) не хранится.

## Проверка вживую

```text
1. Войти: POST /login (admin / password123).
2. Открыть карточку: GET /library/book/49934 → кнопка «Читать».
3. GET /library/book/49934/read   → страница-читалка.
4. GET /library/book/49934/html   → HTML-фрагмент тела книги.
5. POST /library/book/49934/progress (position=percent:12.50) → 204.
```
